# Fonts

The fonts of the talk deck, so that the bench and the slides look the same.
`app.css` loads them with `@font-face`; Vite bundles them into `web/dist`.

| File | Font | Subset | Licence |
| --- | --- | --- | --- |
| `arimo-latin.woff2` | Arimo, variable weight 400–700 | latin | [OFL-Arimo.txt](OFL-Arimo.txt) |
| `arimo-latin-ext.woff2` | Arimo, variable weight 400–700 | latin-ext | [OFL-Arimo.txt](OFL-Arimo.txt) |
| `jetbrains-mono-latin.woff2` | JetBrains Mono, variable weight 100–800 | latin | [OFL-JetBrains-Mono.txt](OFL-JetBrains-Mono.txt) |
| `jetbrains-mono-latin-ext.woff2` | JetBrains Mono, variable weight 100–800 | latin-ext | [OFL-JetBrains-Mono.txt](OFL-JetBrains-Mono.txt) |

Both fonts are under the SIL Open Font License 1.1. The files are the
Google Fonts subsets that the deck embeds.
