2. Before the talk

The day before (needs network)

  5. mkdir -p ~/pk-agent/.claude
echo '{"permissions":{"allow":["mcp__platform-kit"]}}' > ~/pk-agent/.claude/settings.local.json

    Other way: start Claude Code with claude --allowedTools mcp__platform-kit. opencode allows MCP tools without a prompt.

30 minutes before the talk

  10. On a 1920 px projector at 125 % the page is 1536 px wide: the side panel (chat, activity) sits next to the page, and nothing moves when it opens. Below 1100 px (for example the browser and the agent terminal side by side in step 3.2) the side panel opens over the page; the left navigation stays visible. Messages (toasts) show at the bottom right, above the status line of the editor, and go away after 5 s (errors after 9 s); the × closes one at once.

After make fresh the old agent token does not work. Approve the agent again and run the new claude mcp add command. For Claude Code, first run claude mcp remove platform-kit.
