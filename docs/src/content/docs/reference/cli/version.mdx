`pk-metal version` prints the version of the program on one line.

## Synopsis

<CliSynopsis cmd="version" />

The command takes no arguments and has no flags.

## What it does

The build writes the version into the binary. A binary from a release prints the release tag.
A binary that you build without a tag prints `dev`.

## Examples

<Terminal
title="pk-metal version"
text={`
    $ pk-metal version
    v0.9.0
`}
/>

## Objects

The command reads and writes no object. It does not talk to the cluster or to a BMC.
