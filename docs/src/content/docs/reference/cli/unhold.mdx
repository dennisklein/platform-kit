`pk-metal unhold` removes the hold that [](cli:hold) set on a [](kind:HostClaim).
The operator then proposes operations for the claim again.

## Synopsis

<CliSynopsis cmd="unhold" />

<dl>
  <dt>`<claim>`</dt>
  <dd>The name of the claim. The default namespace is `default`. You can also write `<namespace>/<claim>`.</dd>
</dl>

## Flags

<CliFlags cmd="unhold" />

## What it does

1. The command reads the claim.
2. If the claim is not on hold, the command says so and changes nothing.
3. It removes the annotation `metal.pk.io/hold` from the claim.
4. The operator proposes the operations that the claim needs. Each one waits for approval.

## Examples

<Terminal
title="pk-metal unhold"
text={`
    $ pk-metal unhold default/cp-2
    claim default/cp-2 is no longer on hold: the operator proposes operations for it again
    $ pk-metal unhold default/cp-2
    claim default/cp-2 is not on hold; nothing changed
`}
/>
