`pk-metal bootstrap` starts etcd on a new Talos cluster and waits until each node is ready.
It works without the operator. It talks to the Talos API of the nodes directly.

## Synopsis

<CliSynopsis cmd="bootstrap" />

The command takes no arguments.

## Flags

<CliFlags cmd="bootstrap" />

`--endpoint` needs `--node`.

## What it does

1. The command reads the manifests and the secrets bundle, as [](cli:render) does.
2. It makes a talosconfig with a short life.
3. It bootstraps etcd on the control planes. It tries again until etcd runs.
4. It waits until each node runs and is ready.
5. It stops with an error when the time of [`--timeout`](cli:bootstrap#--timeout) ends.

You can run the command again. It does not bootstrap a cluster a second time.

<Callout type="note">
The command does not send a machine configuration. Each node must have its configuration before you start the command. [](cli:boot) sends the configuration through the virtual media of the BMC, out of band. pk-metal never sends a configuration through the maintenance API of Talos, because that API has no authentication.
A node that has no configuration stays in maintenance mode. The command then waits until the time of [`--timeout`](cli:bootstrap#--timeout) ends.
</Callout>

## Examples

<Terminal
title="pk-metal bootstrap"
text={`
    $ pk-metal bootstrap --dir manifests/ --secrets secrets.yaml
    bootstrap: cp-1 running and ready
    bootstrap: cp-2 running and ready
    bootstrap: cp-3 running and ready
    bootstrap: OK: lab is bootstrapped and its nodes are ready
`}
/>

Work on one node only, at an address that is not in its manifest.

```sh
pk-metal bootstrap --dir manifests/ --secrets secrets.yaml --node cp-1 --endpoint 10.0.0.11
```

## Objects

The command reads files, not objects in the cluster: the [](kind:TalosCluster) and [](kind:TalosNode) manifests in [`--dir`](cli:bootstrap#--dir).
On the nodes, it uses the authenticated Talos API to bootstrap etcd and to read the state.

With the operator, the [](ctrl:taloscluster) bootstraps the cluster.
