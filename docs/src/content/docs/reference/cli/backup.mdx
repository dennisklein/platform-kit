`pk-metal backup` works with the etcd snapshots of a Talos cluster.
The operator takes the snapshots on the schedule of an [](kind:EtcdBackupPolicy) and keeps them encrypted.

The operator has no private key. It can store a snapshot, but it cannot read one.
To decrypt, you need an age identity that agrees with a public key in the policy, on your workstation.

<CliSynopsis cmd="backup" />

## Subcommands

| Subcommand | Effect | Changes the cluster |
| --- | --- | --- |
| `now` | Takes a snapshot now and waits until the operator has it in the sink. | Yes: one [](kind:EtcdSnapshot) |
| `list` | Lists the snapshots, the newest first. | No |
| `get` | Downloads one encrypted snapshot. | No |
| `decrypt` | Decrypts a snapshot on your workstation and makes sure that it is intact. | No |

You can put the flags before or after the arguments.

### now

`pk-metal backup now <cluster>`

<CliFlags cmd="backup" sub="now" />

1. The command finds the policy: the EtcdBackupPolicy with that name, or the one policy of the TalosCluster with that name.
2. It makes an EtcdSnapshot with the name `<policy>-manual-<time>`.
3. It waits until the operator stored and verified the snapshot, and prints each progress message.

If the cluster has more than one policy, give the name of a policy.

### list

`pk-metal backup list [<cluster>]`

<CliFlags cmd="backup" sub="list" />

The `STATE` column is `Taking`, `Failed`, `Unverified` or `Verified`.

### get

`pk-metal backup get <snapshot> -o <file>`

<CliFlags cmd="backup" sub="get" />

The command downloads from an S3 sink. It reads the credentials of the sink from a Secret in the namespace `pk-metal`.
It cannot read a snapshot on the backup volume of the operator (a `pvc` sink). Copy the file from the volume first.

### decrypt

`pk-metal backup decrypt (<snapshot> | --in <file.age>) --identity <file> [-o <file.db>]`

<CliFlags cmd="backup" sub="decrypt" />

1. The command reads the age identity file.
2. It decrypts the snapshot, from the sink or from the file of `--in`.
3. It makes sure that the result is an intact etcd snapshot.
4. For a snapshot from the sink, it compares the SHA-256 with the record in the EtcdSnapshot.
5. With `-o`, it also writes the plaintext.

<Callout type="warning">
Delete the plaintext file when the work is complete. It holds each Secret of the cluster. The command writes it with mode `0600` and does not replace a file that exists.
</Callout>

With `--in`, the command does not talk to the cluster.

## Objects

| Object | Access | Purpose |
| --- | --- | --- |
| [](kind:EtcdBackupPolicy) | get, list | Finds the policy and the sink. |
| [](kind:EtcdSnapshot) | create | `now`: the request for a snapshot. |
| [](kind:EtcdSnapshot) | get, list | `list`, `get`, `decrypt`, and the wait of `now`. |
| Secret in `pk-metal` | get | `get` and `decrypt`: the credentials and the CA of the S3 sink. |

## Exit status

<CliExit cmd="backup" />

`now` gives code 1 if the snapshot fails, if the operator stored it but did not verify it, or if the time of `--timeout` ends.
