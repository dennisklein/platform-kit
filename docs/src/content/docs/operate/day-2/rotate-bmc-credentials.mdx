## Goal

Stop the use of the factory password, and change the operator's BMC password on a schedule.

## Before you start

- The endpoints are `Verified`. The operator writes nothing to a machine that it did not verify.
- The factory credentials in the Asset `credentialsRef` work. The operator uses them to make its own account.
- This change does not disturb the machine. It needs no approval.

## How it works

1. The operator makes its own account on the BMC, with the role Administrator.
2. It keeps the password in the Secret `endpoint-creds-<endpoint>` in `pk-metal`.
3. For a rotation, it writes the new password next to the working one, as `next-username` and `next-password`.
4. It sets the new password on the BMC and logs in with it.
5. Only after a good login, it replaces the working password.

The factory account stays as it is. It is the way back in.

## Steps

<Steps>

1. Write an [](kind:EndpointProfile) with a `credentials` block. `maxAge` sets the schedule.

   ```yaml title="managed-bmcs.yaml"
   apiVersion: metal.pk.io/v1alpha1
   kind: EndpointProfile
   metadata:
     name: managed-bmcs
   spec:
     match:
       matchLabels:
         metal.pk.io/vlan: "1034"
     credentials:
       username: pk-metal
       maxAge: 2160h
   ```

2. Apply it.

   ```sh
   kubectl apply -f managed-bmcs.yaml
   ```

3. Monitor the endpoints.

   ```sh
   kubectl get managementendpoints
   ```

   The phase goes through `Configuring` to `Ready`.

</Steps>

<Callout type="note">
To rotate sooner, set a shorter `maxAge`. Without `maxAge`, the operator changes the password only when the Secret is missing.
</Callout>

## Verify

`kubectl describe managementendpoint sim-0001` shows `Configured=True`.

## If it fails

| Reason on `Configured` | Fix |
| --- | --- |
| `RotationFailed` | The BMC refused the new password. The working password stays. Read the message for the password rules of the BMC. |
| `AwaitingVerification` | The endpoint is not `Verified`. See [](rb:host-mismatch). |
| `NTPFailed` | The operator could not write the `ntp` block of the profile. |
