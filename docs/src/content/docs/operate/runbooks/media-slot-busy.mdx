## Symptoms

<dl>
  <dt>Operation</dt>
  <dd>`Failed` at [](act:InsertMedia).</dd>
  <dt>Claim `Provisioned=False`</dt>
  <dd>`SingleMediumUnsupported`, `NoBootableMedia` or `AwaitingBootAsset`.</dd>
  <dt>[](kind:BootAsset)</dt>
  <dd>`Ready=False` with `BuilderUnavailable`, `BuildFailed` or `Building`.</dd>
</dl>

## Impact

The machine does not boot the installer. It stays as it was.

## Diagnose

<Steps>

1. Read the failed step message.

   ```sh
   kubectl -n pk-metal describe hostoperation provision-simhw2288v5000397-0f3c9a1e
   ```

2. Read the boot assets of the node.

   ```sh
   kubectl get bootassets
   ```

3. List the media slots of the BMC.

   ```sh
   pk-metal check --insecure https://192.0.2.21
   ```

</Steps>

## Fix

| Cause | Fix |
| --- | --- |
| The slot holds media from a person | The operator ejects other media first. If the BMC refuses, eject it in the BMC web console. Then retry. |
| The BMC cannot download from the media service | Check `--media-url` and the path from the BMC network. See [](howto:network-checklist). |
| `SingleMediumUnsupported` | One slot, and the slot does not boot an ISO. Talos before 1.12 also causes it, but the operator accepts only v1.14.0 or later. See [](ref:versions). |
| `BuilderUnavailable` | Add the media store component, or set the imager flag that the message names. |
| `BuildFailed` | The BootAsset message has the commands to read the build log. |
| `NoBootableMedia` | The BMC has no slot that mounts an image. Boot the machine another way. |

<Callout type="note">
A one-slot BMC needs an installer with the config in it. [](concept:one-slot-bmc) explains it.
</Callout>

## Verify

Retry the operation with [](cli:retry) and approve it. `insertMedia` succeeds.
