## Symptoms

<dl>
  <dt>[](kind:TalosNode)</dt>
  <dd>`Ready` is not `True`. The reason is `Converging`, `AwaitingContact` or `DialFailed`. `MachineReachable` can show `MaintenanceMode`.</dd>
  <dt>[](kind:TalosCluster)</dt>
  <dd>`Available=False` with `NodesNotReady`. For `KubernetesUnreachable`, start at [](rb:cluster-unavailable).</dd>
  <dt>Operation</dt>
  <dd>[](act:AwaitCheckIn) or [](act:WaitNodeReady) failed.</dd>
  <dt>Alert</dt>
  <dd>`PkMetalNodeNotReady`, for 15 minutes. It fires only for a node of a bootstrapped cluster that answered before. A node that the operator still installs does not page.</dd>
</dl>

## Impact

The workloads of the node do not run. A control plane that is down reduces the etcd margin.

## Diagnose

<Steps>

1. Read the node conditions.

   ```sh
   kubectl describe talosnode w-1
   ```

2. If the node answers, read its services and its kernel log.

   ```sh
   talosctl -n 192.0.2.13 services
   ```

3. If the node does not answer, read its serial console through the BMC.

</Steps>

## Fix

| Reason | Cause | Fix |
| --- | --- | --- |
| `Converging` | Talos runs, but a condition is not met. The message names it. | Correct the named service. |
| `MaintenanceMode` | The machine booted with no config. | The config medium did not mount. See [](rb:media-slot-busy). |
| `DialFailed` | Neither Talos service answers. | Check power, the node address and TCP 50000. |
| `NoAddress` | The node has no address. | Set `spec.address` or a static link address. |
| No network at boot | Wrong NIC MAC, gateway or VLAN in the TalosNode. | Correct the TalosNode. Reinstall. |
| No time or DNS | The node cannot reach NTP or DNS. | Add `TimeSyncConfig` and `ResolverConfig` patches. |
| The console is dark | The kernel argument `console=` names the wrong port. | Correct the schematic. |

## Verify

`kubectl get talosnode w-1` shows `READY` `True`.

## If this does not work

Follow [](howto:collect-diagnostics). For a broken install, see [](howto:reinstall-a-node).
