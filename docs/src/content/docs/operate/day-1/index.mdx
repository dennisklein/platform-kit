## The tasks

| Order | Task | You write | The operator writes |
| --- | --- | --- | --- |
| 0 | [](howto:install-operator) | The site overlay: image, ledger, flags, groups | Nothing on a machine |
| 0 | [](howto:approval-permissions) | Role bindings, the `selfApproval` setting | Nothing |
| 1 | [](howto:network-checklist) | Firewall rules, DHCP reservations | Nothing |
| 2 | [](howto:check-a-bmc) | Nothing | Nothing. The check reads only. |
| 3 | [](howto:enroll-hosts) | [](kind:Asset), credentials Secret, ledger line | [](kind:ManagementEndpoint), [](kind:Host) |
| 4 | [](howto:define-a-cluster) | [](kind:TalosCluster), [](kind:TalosNode), secrets bundle | Rendered machine config |
| 5 | [](howto:install-hosts) | [](kind:HostClaim), your approval | [](kind:HostOperation) |
| 6 | [](howto:pivot) | Nothing | A copy of all objects on the new cluster |
