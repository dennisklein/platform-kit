## Goal

Open every network path that the install needs, before you enrol the first machine.

## Before you start

- You know the address range of the BMC network and of the node network.
- You know the address that the BMCs use to reach the [](term:media-service). This is the `--media-url` flag of the [](ctrl:manager).
- Your network team can change firewall rules and DHCP reservations.

## Steps

Check each row with your network team. The number is the arrow in the figure.

| # | From | To | Port | Why |
| --- | --- | --- | --- | --- |
| 1 | Management cluster nodes | Each BMC | TCP 443 (or the port in the ledger URL) | The operator reads and controls the machine through [Redfish](https://www.dmtf.org/standards/redfish). |
| 2 | Each BMC | The media service address (`--media-url`) | TCP 30443 (NodePort) or your load balancer | The BMC downloads the installer and the machine config. |
| 3 | Each BMC | The image factory | TCP 443 | The BMC downloads the installer ISO, unless you serve it from inside. |
| 4 | Management cluster nodes | Each installed node | TCP 50000 | The operator checks that the node came up and reads its state. |
| 5 | Management cluster nodes | The image factory | TCP 443 | The operator registers the image [](term:schematic). |
| 6 | Each node | DNS, NTP, the image factory registry, `ghcr.io`, `registry.k8s.io` | TCP 443, UDP 53, UDP 123 | Talos pulls its installer image and the Kubernetes images. |

Also do these steps:

1. Give each BMC a fixed address. Use a DHCP reservation or a static address.
2. Write one [](term:ledger) line for each BMC: the BMC MAC and `https://<address>`.
3. Write the static node addresses, the gateway and the VIP in your notes. You need them in the [](kind:TalosNode) and [](kind:TalosCluster) objects.
4. If your BMCs use one virtual media slot, let the management cluster pull `ghcr.io/siderolabs/imager`.

<Callout type="note">
The BMCs do not verify the certificate of the media service.
The manager makes its own certificate when `--media-cert-secret` is not set.
</Callout>

## Verify

1. From a management cluster node, run [](cli:check) against one BMC. The last line is `check:    OK (read-only)`.
2. From the BMC network, open `https://<media-url>/`. The answer `404` is correct.
