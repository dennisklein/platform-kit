When a claim goes, the machine returns to the pool. Its disk must not hold the old node.
If the old disk boots, the machine comes back as a node that no longer belongs, with the keys of its cluster.

## Terms

<dl>
  <dt>Release</dt>
  <dd>The operation that the [](ctrl:hostclaim) proposes when you delete a claim.</dd>
  <dt>Hand-off record</dt>
  <dd>[`status.handOff`](kind:HostClaim#status.handOff) of the claim. It records that a node was installed on a machine. It decides whether a release needs approval.</dd>
  <dt>Disk not wiped</dt>
  <dd>The condition `DiskWiped=False` with reason `InstalledNodeRemains`, and the annotation `metal.pk.io/disk-not-wiped`.</dd>
  <dt>Wipe</dt>
  <dd>An operation that boots a Talos image with `talos.experimental.wipe=system`. The machine ends in Talos maintenance mode with an empty disk.</dd>
</dl>

## Rules

1. A marked Host gets no install and no other operation that turns it on.
2. [](cli:wipe) asks for the wipe. A person approves it.
3. If you know that the disk is empty, remove the annotation yourself. The operator accepts it.
4. The hand-off record changes only through [](cli:reinstall), [](cli:replace) or a removal. Each one resets the disk first.
