A machine has one identity: its serial number.
Two independent sources give it: you, in the [](kind:Asset), and the BMC, through Redfish. The operator continues only when they agree.

## Terms

<dl>
  <dt>Serial anchor</dt>
  <dd>The serial number that the operator reads for a vendor. A Supermicro system gives the board serial. A Huawei system gives the chassis serial.</dd>
  <dt>Host name</dt>
  <dd>The serial anchor in lower case. Each path to the same machine gives the same [](kind:Host).</dd>
  <dt>Verified</dt>
  <dd>The condition that says the two serials agree. `False` with `SerialMismatch` or `MACMismatch` holds the machine.</dd>
  <dt>Mismatch</dt>
  <dd>The phase of a [](kind:ManagementEndpoint) whose facts do not agree with its Asset.</dd>
</dl>

## Why two sources

- A wrong cable or a wrong ledger line can point an Asset to another machine.
- If the operator trusted one source, it could install the wrong machine.
- The identity does not use the address, the endpoint name or the BMC firmware. So two paths to one machine cannot disagree.
